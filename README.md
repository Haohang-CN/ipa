# 清影 iPad 预览版 0.1.5

适配目标：iPad Pro 2021 11 英寸。最低部署版本 iPadOS 17。

**这是 Swift 原生工程和 GitHub Actions 构建配置，不是已经编译好的 IPA。当前环境没有 Xcode，尚未完成苹果平台编译及真机测试，也未验证你报告的 iPadOS 26.7。第一次云端构建可能需要根据日志修正。**

## 你现在要做什么

推荐在 Windows 浏览器中操作。

1. 登录 GitHub，新建一个仓库，例如 `qingying-ipad`，可以选择 Private；勾选添加 README 后创建。
2. 解压本工程包。使用仓库页面的 **Add file → Upload files**，上传解压后的 `App` 文件夹、`project.yml`、`README.md`。不要只上传 ZIP，也不要把它们放进额外的外层文件夹。
3. 添加工作流：在仓库页面点 **Add file → Create new file**，文件名填写 `.github/workflows/ios.yml`，把工程包中同一路径文件的全部内容粘贴进去，然后提交。若你已连同 `.github` 文件夹完整上传，可以跳过此步。
4. 打开仓库的 **Actions → Build iPad IPA → Run workflow → Run workflow**。若提示启用 Actions，先启用。请确认账户允许运行 macOS runner，额度及计费以你的 GitHub 设置为准。
5. 构建成功后，点进此次运行，在底部 **Artifacts** 下载 `Qingying-iPad-build`。解压后可找到 `Qingying-iPad-unsigned.ipa`、`SHA256.txt` 和 `build.log`。
6. 如果出现红叉，下载日志包或复制报错步骤的日志，发回来修复。失败的构建不一定有 IPA；不能把只有日志的包当作安装包。

仓库根目录应直接看到 `App`、`project.yml` 和 `.github`。GitHub 网页对以点开头的文件夹上传不方便，因此第 3 步提供了手动创建方式。

## 安装边界

生成的是**未签名 IPA**，不能直接点开安装。还需要后续在 Windows 上使用适用的签名安装方案；具体方案需要结合当前系统兼容性确认。本工程不包含证书、描述文件或 Apple 账号凭据，也不要求你把 Apple 账号密码上传到仓库。

## 当前工程实现范围

- 深色 iPad 界面，宽屏时左边播放器、右边介绍及选集。
- 推荐、排行、站内搜索；页面提取结果的会话内缓存。
- 线路分组与对应集数，缺失名称时显示线路 1、线路 2。
- AVPlayer 视频输出及自定义半透明控制层：全屏四角按钮、画面双击播放/暂停、进度条与左右滑动定位、长按临时 2 倍速、左侧亮度和右侧应用音量手势、小窗播放。
- 当前播放视频的 MP4/HLS 离线下载、下载列表与本地播放入口。
- 前后跳转 17 秒、上一集和下一集、倍速。
- 后台音频模式和系统媒体控制命令；系统最终展示的按钮由 iPadOS 决定。
- 逐集进度保存、观看历史、再次打开恢复进度；返回片库或退到后台会暂停当前播放。
- 每部剧独立保存片头片尾秒数，当前策略为跳过片尾后结束本集。

上述为代码实现范围，不代表已经在 iPad 上验证成功。

## 尚未移植与已知限制

- 已提供本集 MP4/HLS 下载入口和下载管理；尚无收藏。右侧上下滑动调节的是应用内播放音量，iOS 不提供可靠的公开接口让第三方播放器用手势直接设置系统音量。
- 封面通过携带网页 Cookie、UA 与来源页单独获取，列表没有封面时尝试详情页补取。网站返回限制码或无法解码图片时仍可能显示重试。
- 播放优先尝试提取到的 HLS/MP4；DASH、特殊请求头、跨域解析器、登录验证和失效线路可能无法播放。不会绕过付费或访问限制。
- 页面与内存缓存不会跨 App 重启保留；观看历史、进度及片头片尾设置会保存。
- 搜索现在等待结果页发生实际变化，再按片名筛选；封面补取使用独立网页读取器，避免它打断搜索和播放解析。列表会提前触发懒加载图片，仍受网站图片可用性限制。
- 影片站点的数据和可用性不受本工程控制。请仅使用你有权访问的内容。
